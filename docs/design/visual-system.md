# Politicalverse visual system

Last reviewed: **2026-08-21**

Politicalverse uses an independent, public-service analytical design inspired by the clarity and accessibility of Sveriges riksdag. It does **not** reproduce the Riksdag or Valmyndigheten logos and must never imply that Politicalverse is an official government service.

## Palette

The core palette is based on color values used by the current Sveriges riksdag website, adapted into semantic Politicalverse tokens.

| Politicalverse token | Value | Use |
|---|---:|---|
| `--blue` | `#1c5170` | Primary institutional surface, links and navigation state |
| `--blue-deep` | `#153d54` | Secondary dark surface and footer |
| `--blue-darkest` | `#0b202d` | High-contrast copy on light surfaces |
| `--paper` | `#f4f6f8` | Analytical cards and quiet section backgrounds |
| `--paper-deep` | `#e9f0f4` | Grid, tracks and secondary separators |
| `--acid` | `#e0ed44` | Limited election-cycle emphasis and primary call to action |
| `--focus` | `#d28304` | Keyboard focus outline |
| `--ink` | `#1b1b1b` | Body copy |

Party colors remain independent data encodings from the canonical party registry. They must not be replaced by the institutional palette in charts, maps or party identity.

## Typography and structure

- Open Sans is the preferred face when locally available, followed by the native system sans stack.
- Headlines use firm sans-serif weights and restrained tracking rather than the previous oversized editorial/terminal treatment.
- White and ice-gray surfaces, thin blue-gray rules, compact source labels and clearly bounded data panels establish the institutional tone.
- Lemon is an accent, never a default background for large analytical surfaces.
- `OFFICIAL`, `DERIVED` and future `MODEL` labels keep distinct semantic treatment; color is never their only identifier.

## Independence

The product wordmark and PV mark are original Politicalverse elements. Every public surface should retain the independent-analysis disclaimer and identify Valmyndigheten as the data authority where official election observations are shown.
